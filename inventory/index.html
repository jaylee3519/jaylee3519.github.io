구글 시트 연결 방법 (처음 1번만)
  1. 새 구글 시트를 만듭니다.
  2. 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 기존 코드를 지우고 apps-script.gs 내용을 전부 붙여넣습니다.
  4. 맨 위 TOKEN = 'CHANGE-ME'를 원하는 비밀번호로 바꾸고 저장합니다.
  5. 배포 → 새 배포 → 유형: 웹 앱, 실행 사용자: 나, 액세스 권한: 모든 사용자로 배포합니다. (권한 승인 창이 뜨면 허용)
  6. 나오는 웹 앱 URL과 비밀번호를 위 칸에 넣고 저장합니다.
  7. 직원 폰에는 아래 설정 링크 공유로 보내면 한 번에 설정됩니다.
데이터

CSV 열 순서: 코드, 상품명, 수량, 위치, 최소수량, 메모 (첫 줄 제목은 자동으로 건너뜀). 같은 코드가 있으면 덮어씁니다.
