# 매장 재고관리

스마트폰으로 **상품명·코드 검색** 또는 **바코드 스캔**을 해서 재고를 확인하고 입고·출고·실사를 기록하는 웹 앱입니다.
데이터는 **구글 시트**에 저장되어 여러 직원이 같은 재고를 함께 봅니다.

- 주소: `https://jaylee3519.github.io/inventory/`
- 설치할 필요 없음. 폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 검색 | 상품명·코드·위치로 검색. 초성 검색 가능 (예: `ㅅㅇㄲ` → 새우깡) |
| 바코드 스캔 | **조회** 모드: 스캔하면 재고 현황 표시 / **입고 +1**, **출고 −1** 모드: 스캔할 때마다 바로 반영 (연속 스캔) |
| 사진 인식 | 실시간 카메라가 안 될 때 바코드 사진을 찍어서 인식 |
| 미등록 바코드 | 스캔하면 바로 신규 등록 화면으로 이동 |
| 입고·출고·실사 | 수량과 메모를 넣고 반영. 실사는 실제 센 수량으로 재고를 맞춤 |
| 재고 부족·품절 | 최소 수량 이하이면 빨간색 표시, 필터로 모아보기 |
| 입출고 기록 | 언제, 누가, 몇 개를 바꿨는지 모두 기록 (구글 시트 `기록` 탭) |
| CSV | 엑셀로 내보내기 / 상품 목록 한 번에 가져오기 |

## 처음 설정 (사장님이 1번만)

1. 새 **구글 시트**를 만듭니다. (이름 예: `매장 재고`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 [`apps-script.gs`](apps-script.gs) 내용을 전부 붙여넣습니다.
4. 맨 위 줄 `const TOKEN = 'CHANGE-ME';` 에서 `CHANGE-ME`를 **직원만 아는 비밀번호**로 바꾸고 저장(💾)합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** 클릭 → 권한 승인 창이 뜨면 본인 계정 선택 → (경고 화면이면) *고급 → 이동* → **허용**
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. 폰에서 앱을 열고 **⚙ 설정 → 구글 시트** 선택 → URL과 비밀번호 입력 → **연결 테스트** → **저장**.

시트에는 `재고`, `기록` 탭이 자동으로 생깁니다. 시트에서 직접 고쳐도 앱에 반영됩니다(새로고침).

### 직원 폰 설정

설정 화면의 **설정 링크 공유**를 누르면 카톡 등으로 링크를 보낼 수 있습니다.
직원이 링크를 열고 이름만 입력하면 끝입니다. (링크에 비밀번호가 들어 있으니 직원에게만 보내세요.)

### 상품 목록을 한 번에 넣기

엑셀에서 아래 순서로 열을 만들고 **CSV로 저장** → 설정 → **CSV 가져오기**.

```
코드,상품명,수량,위치,최소수량,메모
8801043014809,새우깡 90g,24,A-3,5,
8801056038861,칠성사이다 500ml,40,냉장고,12,
```

## 알아두면 좋은 점

- **카메라는 https 주소에서만** 동작합니다. GitHub Pages 주소(`https://…github.io`)로 열면 됩니다. 처음 스캔할 때 카메라 권한을 **허용**하세요.
- 아이폰은 Safari, 안드로이드는 Chrome을 권장합니다.
- Apps Script 코드를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)
- 여러 명이 동시에 입출고해도 서버에서 잠금을 걸어 수량이 꼬이지 않습니다.
- 인터넷이 끊기면 마지막으로 받은 재고는 볼 수 있지만 수정은 연결된 뒤에 해야 합니다.
- 설정에서 **이 기기에만** 저장을 고르면 구글 시트 없이 바로 써볼 수 있습니다. 나중에 **이 기기 데이터를 구글 시트로 보내기**로 옮길 수 있습니다.
