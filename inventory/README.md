# 매장 재고관리

스마트폰으로 **상품명·코드 검색** 또는 **바코드 스캔**을 해서 재고를 확인하고, 입고·출고·실사·위치 이동을 기록하는 웹 앱입니다.
한 상품이 여러 곳(지하창고, 1층 매대, 외부창고 등)에 있어도 **위치별 수량**과 **총 재고**를 함께 관리합니다.
데이터는 **구글 시트**에 저장되어 여러 직원이 같은 재고를 함께 봅니다.

- 주소: `https://jaylee3519.github.io/inventory/`
- 설치할 필요 없음. 폰 브라우저(아이폰은 Safari)에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 검색 | 상품명·규격·바코드·위치로 검색. 초성 검색 가능 (예: `ㄱㄴㅂㅌㅁㅆ` → 경남비타민씨) |
| 위치 필터 | `📍 전체 위치`에서 위치를 고르면 그 선반에 있는 상품과 수량만 보임 (선반별 실사에 편리) |
| 위치별 재고 | 상품을 누르면 총 재고와 위치별 수량이 나옴. 위치를 눌러 고른 뒤 입고·출고·실사 |
| 위치 이동 | 창고 → 매대로 옮길 때 "다른 위치로 이동" (총 재고는 그대로, 기록은 남음) |
| 바코드 스캔 | **조회**: 스캔하면 재고 표시 / **입고 +1**, **출고 −1**: 스캔할 때마다 바로 반영 (연속 스캔). 위치가 여러 곳이면 어느 위치인지 물어봄. **작업 위치**를 정해두면 묻지 않음 |
| 바코드 연결 | 엑셀에서 가져온 상품은 바코드가 없음 → 처음 스캔할 때 **기존 상품에 바코드 연결**을 누르면 다음부터 바로 인식 |
| 사진 인식 | 실시간 카메라가 안 될 때 바코드 사진을 찍어서 인식 |
| 재고 부족·품절 | 최소 수량 이하이거나 0이면 빨간색, 필터로 모아보기 |
| 입출고 기록 | 언제, 누가, 어느 위치에서, 몇 개를 바꿨는지 모두 기록 (구글 시트 `기록` 탭) |
| CSV | 엑셀로 내보내기 / 재고표 한 번에 가져오기 |

## 처음 설정 (사장님이 1번만, 컴퓨터 추천)

1. 새 **구글 시트**를 만듭니다. (이름 예: `매장 재고`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 [`apps-script.gs`](apps-script.gs) 내용을 **전부** 붙여넣습니다.
4. 맨 위 줄 `const TOKEN = 'CHANGE-ME';` 에서 `CHANGE-ME`를 **직원만 아는 비밀번호**로 바꾸고 저장(💾)합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** 클릭 → 권한 승인 창이 뜨면 본인 계정 선택 → (경고 화면이면) *고급 → 이동* → **허용**
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. 폰에서 앱을 열고 **⚙ 설정 → 구글 시트** 선택 → URL과 비밀번호 입력 → **연결 테스트** → **저장**.

시트에는 `상품`, `위치별재고`, `기록` 탭이 자동으로 생깁니다.

### 직원 폰 설정

설정 화면의 **설정 링크 공유**를 누르면 카톡 등으로 링크를 보낼 수 있습니다.
직원이 링크를 열고 이름만 입력하면 끝입니다. (링크에 비밀번호가 들어 있으니 직원에게만 보내세요.)

### 재고표를 한 번에 넣기 (CSV 가져오기)

설정 → **CSV 가져오기**. 위치마다 한 줄씩, 첫 줄은 제목:

```
코드,상품명,규격,위치,수량,최소수량,메모,기준일자
,경남비타민씨,300정,5-a 지하창고,11,,,2026-10-21
,경남비타민씨,300정,5-b 지하창고,14,,,2026-10-21
8801043014809,새우깡,90g,1층 a존,24,5,,
```

- 코드(바코드)가 비어 있으면 **상품명+규격이 같은 줄을 한 상품**으로 묶고 자동 코드(`P-…`)를 붙입니다.
- 이미 있는 상품이면 해당 위치의 수량을 덮어씁니다.

## 알아두면 좋은 점

- **카메라는 https 주소에서만** 동작합니다. 처음 스캔할 때 카메라 권한을 **허용**하세요.
  아이폰에서 거부했다면: Safari 주소창 왼쪽 **"가가" → 웹 사이트 설정 → 카메라 → 허용**
- Apps Script 코드를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)
- 여러 명이 동시에 입출고해도 서버에서 잠금을 걸어 수량이 꼬이지 않습니다.
- 인터넷이 끊기면 마지막으로 받은 재고는 볼 수 있지만 수정은 연결된 뒤에 해야 합니다.
- **이 기기에만** 저장을 고르면 구글 시트 없이 바로 써볼 수 있습니다. 나중에 **이 기기 데이터를 구글 시트로 보내기**로 옮길 수 있습니다.
- 매장 재고 데이터(CSV/엑셀)는 이 저장소(공개)에 올리지 마세요. 데이터는 구글 시트에만 저장됩니다.

## 파일 구성 (개발용)

| 파일 | 내용 |
| --- | --- |
| `index.html` | 앱 화면 전체 |
| `core.js` | 재고 처리 로직 (앱의 기기 저장 모드와 구글 시트 서버가 함께 사용) |
| `server.gs` | 구글 시트 읽기/쓰기 부분 |
| `apps-script.gs` | 구글 시트에 붙여넣는 파일 = `server.gs` + `core.js` (`build.sh`로 생성, 직접 고치지 말 것) |
| `lib/html5-qrcode.min.js` | 바코드 인식 라이브러리 ([html5-qrcode](https://github.com/mebjas/html5-qrcode) 2.3.8, Apache-2.0) |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | 홈 화면 추가·오프라인 열기 |
